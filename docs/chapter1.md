## 머신러닝 워크 플로우
![alt text](image.png)
- 수집: 기계에 학습시킬 자연어 데이터 수집
- 점검 및 탐색: 데이터 구조, 데이터 정제 등 전반적인 데이터 디테일 확인
- 전처리 및 정제: 토큰화, 정제, 정규화, 불용어 제거 등의 선행 작업
- 모델링 및 훈련: 기계에 학습을 시키는 단계. 이때 훈련용 데이터, 검증용 데이터, 테스트용 데이터를 분리해야 함.
    - 훈련용: 학습지
    - 검증용: 모의 고사
    - 테스트용: 수능 시험
- 평가: 테스트용 데이터로 성능 평가
- 배포: 완성된 모델을 배포
